# SOC Automation Platform and Threat Hunter (Work in Progress)

This project aims to build a self-hosted SOC automation platform using open-source tools.
It will integrate Wazuh for SIEM, n8n for SOAR automation, and Flask for the web dashboard.
The system collects security events and automates basic incident response.
Alerts are to be mapped to MITRE ATT&CK and NIST CSF for better visibility.
A unified dashboard displays alerts, response status, and compliance information.

The project is currently under active development.

Features and documentation will be updated as development progresses.
Contributions and feedback are welcome.
